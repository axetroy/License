# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not report exploitable details in a public issue. If private vulnerability reporting is unavailable, contact the maintainers privately through a channel listed on the repository profile.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Please allow maintainers time to investigate and prepare a fix before public disclosure.

## Scope

This project implements offline XML license signing and verification. Reports involving signature verification, XML parsing, key handling, the CLI, or the browser playground are in scope. Offline verification cannot provide online revocation, prevent client patching, or protect a private key that is compromised outside this project.
